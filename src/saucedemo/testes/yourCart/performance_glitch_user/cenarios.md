# Cenários de Teste — Carrinho (Cart)

- **CN-CART-001** — Validar exibição dos produtos no carrinho
    - Quantidade (QTY)
    - Nome do produto
    - Descrição
    - Preço unitário

- **CN-CART-002** — Validar remoção de produtos através do carrinho
    - Exclusão do card do item ao clicar em Remove

- **CN-CART-003** — Validar navegação de retorno às compras
    - Redirecionamento ao clicar no botão "Continue Shopping"

- **CN-CART-004** — Validar sincronização do contador do carrinho
    - Decremento do badge no cabeçalho ao remover itens

- **CN-CART-005** — Validar redirecionamento para o fluxo de checkout
    - Acesso à tela de identificação do comprador ao clicar em "Checkout"
